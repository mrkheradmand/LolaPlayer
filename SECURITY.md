# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of Lola Player.

Older versions may not receive security fixes. Users are encouraged to keep the application updated.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Lola Player, please report it privately.

**Preferred reporting method:** Use GitHub's private vulnerability reporting feature, if enabled for this repository.

Please include:

- A description of the vulnerability.
- The affected Lola Player version and macOS version.
- Steps to reproduce the issue.
- The potential security impact.
- Any relevant logs or screenshots, excluding sensitive personal information.

[Report a Security Vulnerability](../../security)

**Do not publicly disclose security vulnerabilities** through GitHub Issues or Discussions before the developer has had an opportunity to investigate them.

## Security Response

Security reports will be reviewed and prioritized according to their potential impact.

Confirmed vulnerabilities may be addressed through software updates and documented in release notes.

Response and resolution times may vary depending on the severity and complexity of the issue.

## Responsible Disclosure

We appreciate responsible security research and ask researchers to avoid accessing other users' data, disrupting services, or engaging in destructive testing.

Thank you for helping keep Lola Player secure.
